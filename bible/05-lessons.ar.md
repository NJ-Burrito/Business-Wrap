# 05 · الدروس المستفادة بصيغة عامة (عربي) — الملف المقابل: 05-lessons.md

**الخلاصة:** كل خلل تقريبًا شحنه خط الإنتاج الأصلي واحد من الأنماط التالية. ابحث هنا بالعَرَض قبل قراءة الشيفرة.

## الأدلة والدمج
| # | الدرس |
|---|---|
| L1 | **الدمج اتحادٌ لا اختيار.** الدمج بالنشر أو باختيار «الملف الأفضل» يُسقط كل حقل لم يعرفه إلا المصدر الخاسر؛ وهكذا اختفت خطوة مرتين وكل الفحوص خضراء. |
| L2 | **حقيقة واحدة، قائمة واحدة، تُحسب مرة واحدة.** مستهلكان يقرآن الحقيقة نفسها من مصدرين مختلفين سيختلفان، والمختلف ليس هو الذي تنظر إليه أبدًا. |
| L3 | **القسم الممتلئ الذي يعود فارغًا مشكلة ملف أولًا** (ملف فحص كُتب فوقه، أو تفريغ باسم مسار أطول، أو ملف تجهيز بمعرّف آخر). |
| L4 | **النموذج الذي يُجمع دون الإجابة عن أسئلة فروعه يُظهر أقل مما فيه.** الحقول خلف زر اختيار لا تظهر حتى يُجاب. والوثيقة التي تقول إن حقلًا أُزيل، والجمع هو الذي لم ينظر، أسوأ من وثيقة قديمة. |
| L5 | **القراءة الفارغة شبهة في الأداة.** صفر كلمة عربية من ملف PDF يعني غالبًا أداة الاستخراج لا الملف: استخدم poppler بالأمر `pdftotext -enc UTF-8`؛ فأداتا pymupdf وpdfium تُسقطان كلمات عربية، واتفاق أداتين قد يكون خطأ اتجاه مشتركًا. |
| L6 | **«رُئي وهو فارغ» إجابة** لا فجوة («لا مرفقات مطلوبة» حقيقة). والغياب المصرَّح به لا يحتاج تأكيدًا. |
| L7 | **اربط بمفتاح ثابت، لا بجزء من الاسم.** الأسماء غير فريدة، وجزء من اسم فتح سجل خدمة أخرى. |
| L8 | **العميل الذي يصحّح رقمًا قد يضيف رقمًا.** قد تنطوي حقيقتان في حقل واحد؛ تحقّق قبل الكتابة فوق القيمة. |
| L9 | **الوثيقة السابقة مصدر للقيم لا للصياغة.** |

## التعديل والتصحيحات
| # | الدرس |
|---|---|
| L10 | **طابِق قائمة التصحيحات بالجدول والمعرّف، لا بالموضع.** |
| L11 | **«طُبّق» يُثبت لكل بند من المخرَج المطبوع** (نص poppler)، ويُبلَّغ بصيغة «طُبّق N من M»، لا «الكل». سجّل نص `expect` ونص `stale` ليبقى الفحص يراقب. |
| L12 | **لا تعدّل نقطة حفظ مرحلة يدويًا أبدًا.** أصلح السبب في ملف تصحيحات أو في القاعدة ثم أعد تشغيل المرحلة؛ أو سجّل التعديل اليدوي بمساره وسببه في الدور نفسه. |
| L13 | **إعادة التسمية أو الترقيم يُبحث عنها في كل مكان** (الملاحظات والقواعد والقوالب والسجل والنص المبني) قبل اعتبارها منجزة. |
| L14 | **الحكم لمرة واحدة يبقى خاصًا بوثيقته.** لا يُرفع إلى خط الإنتاج إلا عبر التجميع: السبب الجذري ← مراجعة معاكِسة بأعداد إصابات متوقعة ← تصويت من خمس زوايا نظر (4 من 5 على الأقل) ← إثبات يكرر الأعداد المتوقعة تمامًا. |
| L15 | **الأصل يبقى بعد التنظيف:** سطر «لماذا» لأي قاعدة محذوفة (التاريخ ومن قرر ومعرّف السجل) ينتقل إلى سجل القرارات. |

## العرض والمخرجات
| # | الدرس |
|---|---|
| L16 | **افحص المخرَج لا المرحلة التي قبله.** تغطية الخط واللوحة والأحجام تُفحص على ملف PDF المطبوع. |
| L17 | **يطبع Chrome خطوط CFF بصيغة Type 3**، فيعمى فحص الخط؛ اطبع من TrueType. |
| L18 | **ضمِّن كل مورد داخل الصفحة** (الخطوط بترميز base64) وانتظر `document.fonts.ready`؛ فقد يرفض Chrome موارد `file://` بصمت. |
| L19 | **كل ما لا يقرأ ملف الأنماط يقرأ السمة** (قوالب الترويسة والتذييل وDOCX والمخطط)؛ ولا تُنسخ رموز الألوان. |
| L20 | **لا تضع علامة الاقتباس المائلة (backtick) في تعليق CSS داخل ملف أنماط مكتوب نصًا قالبيًا في JavaScript:** فهي تُنهي النص بعيدًا عن موضع الخطأ. |
| L21 | **`break-inside: avoid` على صندوق أطول من صفحة** يترك ما قبله وحيدًا؛ حرّر التسلسل. وأثبت تغييرات التخطيط بفحص DOM على كل الوثائق في بيئة معزولة قبل العرض. |
| L22 | **يُبنى DOCX من ملف JSON للوثيقة**، ويملأ مكاني الخط، ويقيس الخطوط الفاصلة بأثمان النقطة، ولا يترك Word يعيد حفظ المتن أبدًا. |
| L23 | **يُلائَم المخطط بحمل أقل لا بتصغير الخط**؛ شكل واحد على صفحة عرضية واحدة. |

## العملية
| # | الدرس |
|---|---|
| L24 | **أي تغيير في خط الإنتاج تغيير في كل وثيقة**؛ عمّمه وإلا فليست مجموعة. وإعادة بناء الوثائق المسلَّمة تكون عن قصد، لا أثرًا جانبيًا. |
| L25 | **المنجز = الفحوص ناجحة والوثيقة مسلَّمة**؛ وتُعدّ بصيغة «أُعيد بناء N، وسُلّم M». |
| L26 | **لكل رسوب في فحص سبب مسجَّل** قبل البناء التالي. |
| L27 | **حين تتعارض قاعدتان قائمتان، اعرضهما جنبًا إلى جنب واسأل مرة واحدة**؛ ولا تختر بصمت. |
