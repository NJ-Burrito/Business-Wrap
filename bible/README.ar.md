## قواعد ثابتة
1. **لا محتوى لأي عميل في هذا المستودع.** لا أسماء جهات ولا شعارات ولا أسماء خدمات ولا أسماء خوادم ولا بيانات دخول ولا أرقام هويات ولا عناوين بريد ولا أرقام هواتف ولا بيانات مجموعة من أنظمة. ويفرض `security/check.py` ذلك على الشجرة وعلى التاريخ كله.
2. **ثنائية اللغة.** تنتج كل وثيقة بنسخة عربية (من اليمين إلى اليسار) ونسخة إنجليزية (من اليسار إلى اليمين) من ملف JSON واحد؛ والزوج وحدة واحدة، فأي إصلاح في جهة يحدث في الأخرى. النص العربي الظاهر لا يحمل تشكيلا أبدا.
3. **الخطوط:** عائلة ثمانية فقط (Serif Text للنص، وSerif Display للعناوين والغلاف). خط Cairo ممنوع، حتى بديلا احتياطيا. ملفات الخطوط لا ترفع إلى المستودع أبدا (`fonts/README.ar.md`).
4. **الشعارات:** خانات الشعار في الوثيقة تشحن فارغة للمستخدم. والعلامة المائية الخاصة بالأداة تظهر في واجهة المحرر فقط، ولا تظهر في أي مخرج (PDF أو DOCX أو الطباعة أو ملف التعديلات JSON أو حزمة السمة أو تصدير «حفظ HTML»).
5. **الأدلة لا الذاكرة.** لكل قسم مصدر واحد مسمى؛ وإذا غاب المصدر طبعت فجوة مصرح بها أو سؤال مفتوح، لا قيمة مختلقة.
6. **التعديل عبر العقد.** تعديلات الإنسان تكتب في ملف التعديلات JSON وتطبق على ملف JSON للوثيقة؛ ولا يعدل ملف JSON للوثيقة يدويا أبدا.
