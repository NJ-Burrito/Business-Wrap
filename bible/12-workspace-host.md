## Document library (A2) — `editor/ext/10-library.*`, `engine/routes/library.mjs`, `engine/import/`
- The services built into the HTML are **templates** (read-only). The first Save of a template or of a new blank document creates a library entry `doc-<uuid>` and switches to it; the template returns to its built state. Later Saves update the entry.
- Store: IndexedDB `bw-library` (in-memory when storage is blocked); served: mirrored to `HISTORY\library\<id>.json.gz`.
- **The list copy is always the latest:** every change of a library document is autosaved into its entry (0.6 s after it; on pagehide at once); the «آخر حفظ» stamp beside the change counter says when (list · HTML) and replaces the «حُفظ تلقائياً» toast. A reload with `#doc=<id>` reopens that document; a draft newer than the entry (same base, the entry's ops plus more) is applied quietly, no banner.
- **Open here** sets `#doc=<id>` (`history.replaceState`) and closes the drawer; a template clears it. Every open path (list, new, import, duplicate, from template, resume) goes through `show()` and so emits `open(svc, ed)` (the provenance log attaches there).
- Drawer «المستندات»: search, open here, open in a new tab (`#doc=<id>`), duplicate, «نسخ كقالب», delete (Trash, restore, delete for good), new document (`samples/blank`), «القوالب» (a new document from a saved template: same design, header/footer items, logos, page setup and chapter/section titles, empty bodies), and per-row metrics (edits, active minutes, contributors, last signer, locked) read from the document's provenance log with `BWLOG1.metrics` (read only).
- Import (`engine/import/`): a Save-HTML in the page; any other HTML, DOCX (python-docx through uv, `docx_items.py`) and PDF (`pdftotext -layout -enc UTF-8`, the title from `pdfinfo`; never pymupdf for Arabic) through `POST /api/import`. **Structure kept:** headings from Heading styles, `h1–h6` or numbering (`2.1`, glued `2.1وصف` as pdftotext gives it); numbered headings must follow on and, when the PDF has a contents page, appear in it; tables become table blocks; the running header/footer and the contents pages are dropped. **Title** = the document's own: its metadata title, the «عنوان الوثيقة» row, a Title paragraph, the first cover line; the file name only when there is none. The front matter before chapter 1 is not imported as a chapter (the open question says so).
- Gate: `tests/library.test.mjs`.

## «تغييرات» timeline (A9) — `editor/ext/11-timeline.*`
- Per edition `marks: [{at, n, kind}]` (`checkpoint | save | saveHtml | export`) and `epochIds` (the live op ids at the last Save HTML). Counter = ops added since that point + ops undone since it. Save and PDF/DOCX export add a mark and keep the count.
- Checkpoints: after 2 minutes idle, after 25 ops since the last mark, and by hand. ◀ / ▶ = undo / redo of one action group; a row click travels there; travel never deletes (the future stays on the redo stack).
- Persisted in `localStorage bw:tl:<set>`, in library entries and inside the Save-HTML file. Gate: `tests/timeline.test.mjs`.
- «مقارنة بآخر حفظ HTML»: the document at the epoch (the epoch op ids applied to the base) against now, text leaf by text leaf; «استرجع هذا التغيير» sets one text back (one `setText`), the others stay. Limit: an inserted or deleted block shifts the paths after it. Gate: `tests/library.test.mjs`.

## Background host and resume (A10) — `engine/host.mjs`, `engine/routes/session.mjs`, `editor/ext/12-session.*`
- `start({editor, port, open}) → {pid, port, url}` spawns `serve.mjs` detached (next free port), `.local/host.json` holds `{pid, port, token, browserPids, tabs}`; `stop() → {stopped, pids}`; `status() → {running, pid, port, tabs}`.
- Each tab: `EventSource /api/session/live`, state pushed 0.4 s after a change → `HISTORY\sessions\<run>\<tab>.json`. On pagehide and when the tab is hidden, `sendBeacon /api/session/flush` carries only the edits since that push (`delta: {ed: {from, prev, ops}}`, a beacon holds at most 64 KB); a flush with no push yet goes without the base text, which the server takes back from the library mirror. The last connection gone → 4 s → the server waits for a flush still arriving (3 s ceiling) → `run.json`, the host's own browser profile closed, exit 0.
- A tab whose page closes while others stay open (and does not reconnect within 4 s: a reload does) leaves the run (`<run>\closed\`), so a resume brings back only the tabs open at shutdown. The tab that asked becomes the first resumed tab (it navigates itself); the server opens the others.
- The profile travels with the host: every push carries `bw:profile`/`bw:actor` once into `.local/profile.json`, and `GET /` hands it back in `#bw-host-profile` (a data block, CSP unchanged); a tab on a new port or browser profile is not asked «من أنت؟» again.
- Relaunch: a modal offers (1) resume everything — **the server** opens the browser with all URLs, 30 per command line, own `--user-data-dir` under `.local/edge-profile` (a page can open only one popup per gesture) — or (2) new work (the run goes to `sessions\archive\<date>\`).
- The host closes only browsers on its own profile; nothing it did not start. Gate: `tests/host.test.mjs` (ends with a process sweep).
- 0.15.9 browser: Google Chrome is the standard (order: `BW_BROWSER`, the Settings choice in `.local/browser.json`, Chrome, the OS default, Edge, any Chromium; `engine/export.mjs` `chooseBrowser`). Edge keeps `.local/edge-profile` (the old name); every other browser gets its own sub-folder (`edge-profile/chrome`, `edge-profile/operagx`, ...), never another vendor's profile. A non-Chromium default (Firefox, Safari) is opened with the OS opener and cannot be closed by the host. The OS default is only read, never changed. Gate: `tests/browser-0159.test.mjs`.
- 0.15.9 resume popup (owner request): the last session's documents are a list (title, last-edited time, language); tick several or press one to open it alone (`POST /api/session/resume {runId, tab, tabs:[...]}`: the others stay offered); search, select all / clear act on what is shown; «continue all»; «open an older document» lists the save folder's Documents newest first (`GET /api/session/documents?q=`, `GET /api/session/document?id=`); a new blank document; «not now» / Esc change nothing. MCP: `recent_documents`, `open_recent_document`. Gate: `tests/resume-0159.test.mjs`.
- 0.15.9 tabs stay awake: the launch flags cover every Chromium browser's sleep names, and the page keeps itself awake for a tab opened in a browser the user already runs (a loopback WebRTC data channel keeps it out of the intensive timer throttle; a dedicated worker is the heartbeat clock). A tab that vanishes without a goodbye (a discarded or killed page) is `lost`, not closed: TAB_ASLEEP with what to do, its state kept; reloaded it gets its work back. Measured in real Chrome: `tests/awake-0159.test.mjs`.

## An agent through the MCP, end to end (0.16.0) — `mcp/editor-tools.mjs`, `engine/routes/editor-bridge.mjs`
- **Cold start from the MCP alone.** `open_in_editor` with no arguments starts the host and opens a blank tab (no library document is made). `editor_new` starts the host and opens its own window when there is none (an automation tab: no resume popup, never asleep). A second host is refused when another state folder's host already answers on the port; `close_editor` leaves a host another running MCP server started and names it under `skipped`.
- **Values from files.** An op value may be `{"$file": "<absolute path>"}`: an image becomes a checked base64 data URI, a `.json` file its parsed value, any other file its text. A data URI that does not decode (truncated, bad PNG checksum, wrong signature) is `BAD_OP` here, in the CLI and in the host, whoever calls. Never type a logo as base64 through the model.
- **Visible edits.** `editor_ops` is validated whole, then applied op by op in order (one undo group, `g.0 g.1 …`). The person sees a small «agent editing: <section>» chip with the time of the last edit, the block just edited is outlined, the page does not scroll and the caret in a block being typed in stays. An op on the block being typed in is merged, not blocked.
- **Retries are safe.** Every `editor_ops`, `editor_new`, `editor_assign_project`, `editor_trash`, `exportPdf`, `saveHtml` and `share` carries a `request_id` (the tools make one when you give none and reuse it for their one automatic retry). The same id is applied once and answers `replayed: true`. A read that times out is asked once more.
- **Exports.** `editor_action exportPdf {name?, destination?, docx?}` answers `{pdf, folder, docx?}`; the PDF is written under a temporary name and renamed when final; it has its own ceiling (`BW_EXPORT_TIMEOUT_MS`, 120 s). An agent export never opens the save-folder question.
- **The save folder is never moved silently.** Every editor reply and `host_health` carry `workspace {root, chosen, changed?{from, to, at, by}}`.
- **Library.** Ids are stable: the same files give the same library id after a restart (the host keeps `library/sources.json`; changed files get a fresh id). `editor_assign_project`, `editor_trash` (`restore: true` brings it back), `editor_list_documents include_trashed` (rows carry `deletedAt`), `editor_action verifyHistory` (`{ok, issues[]}`, what the tamper banner is based on).
- **The host stays.** A host an agent used in the last 30 minutes (`BW_AGENT_KEEP_MS`) does not exit when its last tab closes; a busy host (a PDF is printing) is reused, never asked to stop.
- **Large values in the ledger.** A new provenance entry keeps a string over 8 KB as `{$blob: sha256, bytes, head}`; the document and its edition history still hold the value (older entries are untouched).

### For agents that script the machine around the editor
- Never send a key press to the editor with a scripted `SetForegroundWindow`: it can fail silently and the key lands in another program. Check `GetForegroundWindow` first, or better use `editor_action` (zoom, find, save, theme, nextPage) which needs no focus.
- Capture the editor with `PrintWindow` on its window handle (works without focus) and not with `AppActivate` plus `CopyFromScreen`, which captures whatever window is in front.
