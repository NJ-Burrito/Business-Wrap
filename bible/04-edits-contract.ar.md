# 04 · عقد التعديلات (عربي) — الملف المقابل: 04-edits-contract.md

**الخلاصة:** لا يغيّر المحرر ملف JSON للوثيقة أبدًا. بل يكتب `edits.json`: قائمة مرتّبة من العمليات على مؤشرات JSON وفق RFC 6901. إعادة تطبيق العمليات على الوثيقة الأساسية (المطابَقة بقيمة `baseHash`) تعطي الوثيقة المعدَّلة. المخطط: `contracts/edits.schema.json` (الإصدار 1)، وقد اعتمده محرّك المحرر.

## الغلاف
| الحقل | المعنى |
|---|---|
| `version` | `1` |
| `document` | معرّف الوثيقة |
| `baseHash` | `sha256:<hex>` لبايتات ملف JSON الأساسي؛ وتُرفض إعادة التطبيق عند عدم التطابق |
| `locale` | `ar` (من اليمين إلى اليسار) أو `en` (من اليسار إلى اليمين): النسخة المعدَّلة |
| `createdAt` و`author` | اختياريان؛ والمؤلف أحرف أولى أو نص حر، لا بريد ولا رقم هوية أبدًا |
| `theme` | تجاوزات اختيارية للرموز بمسار DTCG (‏`"color.role.primary": "#1f6f5c"`) |
| `ops[]` | التعديلات بترتيبها |

## العمليات
| العملية | الحقول | الاستخدام |
|---|---|---|
| `setText` | `path` و`value` و`old` | تغيير نص طرفي: فقرة أو خلية أو عنوان أو تسمية |
| `replace` | `path` و`value` و`old` | استبدال عقدة كاملة |
| `insert` | `path` (رقم موضع أو `-`) و`value` | إضافة كتلة أو صف أو فقرة أو قصة |
| `delete` | `path` و`old` | حذف عنصر؛ ويحفظه `old` للتراجع |
| `move` | `from` و`path` | إعادة الترتيب بالسحب أو بلوحة المفاتيح (بدلالة النقل في JSON Patch) |
| `duplicate` | `path` و`to` (افتراضيًا: بعده مباشرة) | نسخ عنصر |

تُحلّ المؤشرات على الحالة بعد كل العمليات السابقة. ويجعل `old` كل عملية قابلة للعكس، وهذا هو سجل التراجع.

## القواعد
1. **عبر العمليات فقط.** الحفظ = كتابة `edits.json`؛ والتصدير = إعادة التطبيق ثم العرض. التعديل اليدوي على ملف JSON للوثيقة يضيع عند إعادة بناء المرحلة التالية.
2. **فحص التعارض:** عملية `setText` تختلف قيمتها الحالية عن `old` تعارضٌ؛ يعرض المحرر القيمتين ويسأل، ولا يكتب فوقها بصمت.
3. **إعادة الترقيم** بعد الإدراج أو الحذف أو النقل يتولاها محرّك العرض من الموضع، ولا تُخزَّن في العمليات.
4. **اللصق نص خام.**
5. **التعديلات المتكررة خلل في المنبع.** إذا ظهرت العملية نفسها في عدة وثائق، فأصلح قاعدة المصدر؛ فملف التعديلات لحكم إنساني على وثيقة واحدة.
6. **لا أسرار ولا علامة مائية:** ملف التعديلات مخرَج؛ لا يحمل بيانات دخول ولا بيانات شخصية سوى الأحرف الأولى، ولا العلامة المائية للمحرر أبدًا.

## مثال
```json
{ "version": 1, "document": "SAMPLE-001", "baseHash": "sha256:<64 hex>", "locale": "ar",
  "ops": [
    { "op": "setText", "path": "/chapters/0/sections/0/blocks/0/paragraphs/0", "value": "صياغة جديدة.", "old": "صياغة قديمة." },
    { "op": "move", "from": "/chapters/1/sections/0/blocks/2", "path": "/chapters/1/sections/0/blocks/0" } ] }
```
