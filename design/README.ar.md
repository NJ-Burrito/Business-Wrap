# حزم التصميم (عربي) — الملف المقابل: README.md

**الخلاصة:** حزمة التصميم = ملفا رموز بصيغة DTCG + ملف تعريف للخطوط + ملاحظات التخطيط. يفحص `design/build.py` لوحة الألوان ثم يحوّل الحزمة إلى `theme.json`، وهو الملف المسطّح الوحيد الذي يقرؤه محرر HTML وطباعة PDF ومنشئ DOCX جميعًا.

| المجلد | المحتوى |
|---|---|
| `ours/` | الحزمة الافتراضية (`pack.json` ← `theme.json` المولَّد) |
| `custom/` | خانة رفع حزمتك؛ مستثناة من git عدا ملف README |
| `build.py` | محوّل الحزمة إلى سمة (يرفض لوحة ألوان راسبة أو خطًا ممنوعًا) |

العقد: `bible/contracts/design-pack.schema.json`. المنهج الكامل: `bible/06-design-system.ar.md`.

## بناء حزمة مخصّصة أو رفعها (خمس خطوات)
1. انسخ `ours/pack.json` إلى `custom/<name>/pack.json`، وانسخ `palette/tokens.json` و`typography/tokens.json` بجانبه، ووجّه `tokens` إلى النسختين.
2. غيّر الألوان المرجعية أو الأدوار أو الأحجام في النسختين، مع الإبقاء على كل اسم دور (القوالب تقرؤها).
3. شغّل `python design/build.py design/custom/<name>/pack.json`، فيكتب `theme.json` بجانبه، أو يطبع زوج التباين الراسب.
4. حمّلها: في المحرر من «السمة ← تحميل حزمة»، أو بالخيار `--theme design/custom/<name>/theme.json` عند التصدير.
5. الشعارات إلى `logos/` (ملفاتك)، والخطوط إلى `fonts/custom/`.

## كيف يصل كل رمز إلى كل مخرَج
| الرمز | محرر HTML وPDF | DOCX |
|---|---|---|
| `color.role.*` | متغير CSS بالصيغة `--c-<role>` | لون النص وتظليل الخلية ولون الحد |
| `font.family.text/display` | `font-family` للمتن وللعناوين | مكانا الخط `w:rFonts` للحروف اللاتينية **و**`w:cs` للنص العربي |
| `font.size.*` | قيمة `pt` في القاعدة المقابلة | `w:sz` و`w:szCs` (أنصاف النقاط) |
| `rule.*` | سماكة `border-*` | `w:sz` بأثمان النقطة |
| `page.*` | حجم `@page` وهوامشها | حجم صفحة القسم وهوامشه |
| `space.*` | الهوامش والحشوات | المسافة قبل الفقرة وبعدها، وهوامش الخلايا |
