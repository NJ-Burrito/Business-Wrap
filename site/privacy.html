Privacy

Updated 2026-10-28 · applies to Business-Wrap 0.11.0 and this website

Everything stays on your machine. Business-Wrap uploads nothing.

The tool

  • The editor is a local HTML page. It makes no network request for documents, edits, themes or fonts.
  • PDF printing runs a local headless Chrome or Edge. DOCX building runs locally in Python.
  • No telemetry, analytics, crash reports or account. No cloud storage.
  • Browser storage, when used for an unsaved draft, stays in that browser profile.
  • Local learning keeps its journal in .local/learning/ on your computer only. It never enters a document, an export or a webhook.

The only network use

  • Update check: at most once a day, a request to the public GitHub release list. Switch it off in Settings or with node update/cli.mjs --off. Opened from a file (file://), the editor makes no request at all.
  • Webhooks: only to an address you set yourself, on save and export.
  • The crawler: only the service you point it at, and it stops before any final action unless you ask twice.
  • What you choose: cloning the repository and installing packages.

This website

  • Hosted on GitHub Pages. GitHub may keep server logs under its own privacy statement.
  • No cookies, analytics or third-party requests. Your language and theme choice is kept in your browser's local storage.

Questions

Open an issue on GitHub, or see Support.

الخصوصية

آخر تحديث 2026-10-28 · ينطبق على بزنس راب 0.11.0 وعلى هذا الموقع

كل شيء يبقى على جهازك. بزنس راب لا يرفع شيئا.

الأداة

  • المحرر صفحة HTML محلية، لا ترسل أي طلب شبكة للوثائق أو التعديلات أو السمات أو الخطوط.
  • طباعة PDF تعمل بمتصفح Chrome أو Edge محلي دون واجهة، وبناء DOCX يعمل محليا بلغة Python.
  • لا قياس للاستخدام ولا تحليلات ولا تقارير أعطال ولا حساب. ولا تخزين سحابي.
  • تخزين المتصفح، إن استُخدم لمسودة غير محفوظة، يبقى في ملف ذلك المتصفح.
  • التعلّم المحلي يحفظ سجله في .local/learning/ على جهازك فقط، ولا يدخل أي وثيقة أو تصدير أو خطاف ويب.

الاستخدام الوحيد للشبكة

  • فحص التحديث: مرة في اليوم على الأكثر، طلب إلى قائمة الإصدارات العامة على GitHub. أوقفه من الإعدادات أو بالأمر node update/cli.mjs --off. وعند فتح المحرر من ملف (file://) لا يرسل أي طلب.
  • خطافات الويب: إلى عنوان تحدده أنت فقط، عند الحفظ والتصدير.
  • المسح: إلى الخدمة التي توجّهه إليها فقط، ويتوقف قبل أي إجراء نهائي إلا إذا طلبت ذلك مرتين.
  • ما تختاره أنت: نسخ المستودع وتثبيت الحزم.

هذا الموقع

  • مستضاف على GitHub Pages، وقد يحتفظ GitHub بسجلات الخادم وفق بيان الخصوصية الخاص به.
  • لا ملفات تعريف ارتباط ولا تحليلات ولا طلبات إلى أطراف ثالثة. واختيارك للغة والمظهر يُحفظ في التخزين المحلي لمتصفحك.
