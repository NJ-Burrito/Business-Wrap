Privacy

Last updated 2026-10-28 · applies to Business-Wrap 0.15.5 and this website

Everything stays on your machine. Business-Wrap uploads nothing.

On this page

  1. The tool
  2. The only network use
  3. This website
  4. Questions

1The tool

  • The editor is a local HTML page. It makes no network request for documents, edits, themes or fonts.
  • PDF printing runs a local headless Chrome or Edge. DOCX building runs locally in Python.
  • No telemetry, analytics, crash reports or account. No cloud storage.
  • Browser storage, when used for an unsaved draft, stays in that browser profile.
  • Local learning keeps its journal in .local/learning/ on your computer only. It never enters a document, an export or a webhook.

2The only network use

  • Update check: at most once a day, a request to the public GitHub release list. Switch it off in Settings or with node update/cli.mjs --off. Opened from a file (file://), the editor makes no request at all.
  • Webhooks: only to an address you set yourself, on save and export.
  • The crawler: only the service you point it at, and it stops before any final action unless you ask twice.
  • What you choose: cloning the repository and installing packages.

3This website

  • Hosted on GitHub Pages. GitHub may keep server logs under its own privacy statement.
  • No cookies, analytics or third-party requests. Your language and theme choice is kept in your browser's local storage.

4Questions

Open an issue on GitHub, or see Support.
