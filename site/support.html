Support

Start with the guide. Still stuck? Open a GitHub issue.

Read first

  • The guide: requirements, quick start, troubleshooting, backup, hand-over.
  • What changed in each version, with migration notes.
  • The MCP server: every tool and its arguments.

Common fixes

  • Fonts right in the editor, wrong in the PDF: print from TrueType cuts (fonts/README.md).
  • Python crashes printing Arabic on Windows: set PYTHONUTF8=1.
  • No update popup: open the editor through npm run serve. From file:// it cannot check.

Ask or report

  • GitHub issues for bugs and questions. Include the version (node update/cli.mjs --check) and the gate line you saw.
  • Never attach client documents, credentials or real personal data. Use the sample service to show the problem.
  • Security problem: use the contact on the portfolio. Please do not open a public issue for it.

الدعم

ابدأ بالدليل. وإن بقيت المشكلة فافتح بلاغا على GitHub.

اقرأ أولا

  • الدليل: المتطلبات، والبدء السريع، وحل المشكلات، والنسخ الاحتياطي، والتسليم.
  • ما الذي تغيّر في كل إصدار، مع ملاحظات الترحيل.
  • خادم MCP: كل أداة ووسائطها.

حلول شائعة

  • الخطوط صحيحة في المحرر وخاطئة في PDF: اطبع من نسخ TrueType (fonts/README.md).
  • توقف Python عند طباعة العربية على Windows: اضبط PYTHONUTF8=1.
  • لا تظهر نافذة التحديث: افتح المحرر عبر npm run serve، فمن file:// لا يستطيع الفحص.

اسأل أو أبلغ

  • بلاغات GitHub للأعطال والأسئلة. اذكر الإصدار (node update/cli.mjs --check) وسطر الفحص الذي ظهر لك.
  • لا ترفق وثائق العملاء ولا بيانات الدخول ولا بيانات شخصية حقيقية. استخدم الخدمة النموذجية لتوضيح المشكلة.
  • مشكلة أمنية: استخدم وسيلة التواصل في الموقع الشخصي، ولا تفتح لها بلاغا عاما.
