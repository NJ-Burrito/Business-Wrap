# ADHD-friendly UI patterns

Retrieved 2026-10-27.

## Verdict
Follow W3C COGA "Making Content Usable": clear purpose, one step at a time, few interruptions, little content per view, undo everywhere.

| Claim | Grade | Source |
|---|---|---|
| "Making Content Usable" is a W3C Working Group Note (29 April 2021) with 8 objectives, including Focus, Avoid Mistakes and Correct Them, Processes Not Reliant on Memory | V | https://www.w3.org/TR/coga-usable/ |
| Pattern 4.2.1: make the purpose of a page clear; 4.2.4: show current location and progress so a user can resume after losing focus | V | https://www.w3.org/TR/coga-usable/ |
| Patterns 4.6.1 Limit Interruptions and 4.6.3 Avoid Too Much Content | V (titles) | https://www.w3.org/TR/coga-usable/ |
| COGA guidance lists ADHD among the conditions it addresses | V | https://accessibility.education.gov.uk/knowledge-hub/coga |

## Applied in Business-Wrap
Verdict line first; short labelled blocks; tables for rows; icon + word for states (never colour alone); one primary action per screen; undo on every edit; a visible "unsaved / saved / exported" state.
