# الدليل: التثبيت، البدء السريع، حل المشكلات، النسخ الاحتياطي، التسليم (عربي) — الملف المقابل: guide.md

## 1. المتطلبات (إصدارات مجرَّبة في 2026-10-27)
| الأداة | الإصدار المجرَّب | السبب |
|---|---|---|
| Windows | 11 | المنصة الأساسية؛ وmacOS وLinux لم يُجرَّبا |
| Node.js | 24.x | محرّك المحرر ومحرّك العرض والطباعة عبر Playwright |
| Python | 3.12 (يلزم 3.11 فأحدث لأجل `tomllib`) | الفحوص وبناء التصميم ومنشئ DOCX |
| uv | 0.12 | حزم Python (‏`uv pip install` و`uvx`)، ولا يُستخدم pip أبدًا |
| Google Chrome | 155 فأحدث (131 فأحدث لصناديق هوامش الصفحة في CSS) | طابعة PDF |
| poppler (‏`pdftotext`) | 25.x | الحكم على النص العربي في ملفات PDF؛ وقد يسبقه على Windows إصدار قديم من xpdf في PATH، فمرّر `-enc UTF-8` |
| git | 2.4x فأحدث | فحص التاريخ في فحص الأمان |
| gitleaks (اختياري) | 8.28 فأحدث | محرّك ثانٍ للقواعد نفسها |

## 2. البدء السريع (Windows، خطوة بخطوة)
1. انسخ المستودع الخاص: `git clone <رابط المستودع>` ثم `cd Business-Wrap`.
2. ثبّت حزم Node: ‏`npm install`.
3. الخطوط: اتبع `fonts/README.ar.md` (اضبط `BW_FONT_DIR`، وحوّل إلى TrueType، واضبط `BW_FONT_TTF_DIR`).
4. فعّل UTF-8 لـ Python في هذه الطرفية: `$env:PYTHONUTF8 = "1"` (PowerShell).
5. ثبّت خطاف الأمان المحلي: `git config core.hooksPath .githooks`.
6. افحص التصميم: `python design/build.py` ← يطبع نتائج التباين ويكتب `design/ours/theme.json`.
7. افتح المثال في المحرر (انظر `editor/README.md`)، وبدّل بين العربية والإنجليزية بمفتاح الاتجاه، وأجرِ تعديلًا واحفظ: يظهر `edits.json` بجانب الوثيقة.
8. صدّر PDF وDOCX من المحرر أو من سطر الأوامر في `engine/`، واقرأ كل سطر فحص يطبعه.
9. قبل أي رفع: يجب أن ينتهي `python security/check.py` بعبارة `0 finding(s)`.

## 3. حل المشكلات
| العَرَض | السبب | الحل |
|---|---|---|
| الخطوط سليمة في المحرر وخاطئة في PDF | رفض Chrome الخط المحمَّل من `file://` في صفحة `setContent` | ضمِّن الخطوط بترميز base64 وانتظر `document.fonts.ready` قبل الطباعة |
| خطوط PDF تظهر «Type 3» بلا أسماء، والفحص أعمى | مخططات CFF (‏`.otf` و`.woff2`) طبعها محرّك Skia في Chrome | اطبع من TrueType (‏`fonts/README.ar.md`) |
| خط بديل (Segoe UI أو Arial) يظهر لبعض الرموز | الخط لا يحمل تلك الرموز (☐ و←) | استبدلها برموز يحملها الخط قبل الطباعة؛ وفحص تغطية الخط يقرأ ملف PDF المطبوع |
| الحروف العربية منفصلة | `letter-spacing` على العربية، أو كسر إجباري للكلمات | أزل تباعد الأحرف؛ ولا `word-break` ولا `overflow-wrap: anywhere` على العربية |
| النص العربي المنسوخ يقسم الكلمات («المدير ية») | ضبط المسافات بين أزواج الحروف فتح فجوات | ‏`font-kerning: none` |
| ‏`(SRS)` تُطبع `)SRS(`، وفواصل القوائم ينقلب ترتيبها | علامات ترقيم محايدة الاتجاه حول مقاطع معزولة | غلّف العبارة اللاتينية كاملة في `<bdi>` واحد |
| ‏`pdftotext` لا يعيد نصًا عربيًا | إصدار xpdf دون `-enc UTF-8`، أو pymupdf أو pdfium | استخدم poppler مع `-enc UTF-8`؛ ولا تثق باتفاق أداتين |
| ينهار Python عند طباعة العربية | ترميز cp1252 في طرفية Windows | ‏`PYTHONUTF8=1` |
| يُسقط فحص الأمان سطرًا كتبته عمدًا (مثال توثيقي) | السطر يطابق قاعدة | أضف `bw-allow:<rule-id>` على ذلك السطر، أو أعد صياغته |
| يُسقط فحص الأمان مدخلًا يبدأ بـ `history:` | الإصابة في التزام قديم | إن لم يُرفع: عدّل ذلك الالتزام أو أعد بناءه؛ وإن رُفع: غيّر السر، ثم أعد كتابة التاريخ بموافقة المالك |

## 4. النسخ الاحتياطي والاستعادة (التعديلات والمسودات)
- ما يُحفظ: ملف JSON للوثيقة (`03-document.<locale>.json`)، وملف `edits.json` الخاص به، و`theme.json` إن خُصّص. والثلاثة معًا تعيد إنتاج كل المخرجات.
- النسخ الاحتياطي: انسخ الملفات الثلاثة إلى مجلد مؤرَّخ (`backup/2026-10-27/`) أو إلى مستودع خاص؛ وملف التعديلات نص صغير آمن للتتبع بالإصدارات.
- الاستعادة: افتح ملف JSON للوثيقة في المحرر وحمّل ملف التعديلات؛ يتحقق المحرر من `baseHash` ويرفض أساسًا غير مطابق.
- مسودات المتصفح: قد تحفظ جلسة المحرر غير المحفوظة مسودة في تخزين المتصفح، وقد تختفي (نافذة خاصة أو بيانات ممسوحة). احفظ إلى `edits.json` قبل الإغلاق.
- لا تحفظ النسخ الاحتياطية في مكان عام أبدًا؛ فقد تحمل المخرجات محتوى العميل.

## 5. تسليم وثيقة إلى زميل
1. صدّر المخرجات (PDF وDOCX).
2. أرسل مجموعة التسليم: ملف JSON للوثيقة + `edits.json` + `theme.json` (والشعارات المسموح له باستخدامها). لا تُرسل الخطوط: يثبّت الزميل نسخة مرخّصة (`fonts/README.ar.md`).
3. يفتح الزميل ملف JSON للوثيقة ويحمّل ملف التعديلات ويتابع؛ وتُضاف تعديلاته إلى الملف نفسه.
4. اتفقا على من يعدّل تاليًا: كاتب واحد في كل مرة لكل ملف تعديلات؛ ويكون الدمج بإعادة تطبيق ملف بعد الآخر، مع حل أي تعارض في `setText` يعرضه المحرر.
