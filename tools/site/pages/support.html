2Common fixes

  • Export or print does nothing: open the editor through npm run serve, not from the file on disk.
  • Fonts right in the editor, wrong in the PDF: print from TrueType cuts (see fonts/README.md).
  • Python crashes printing Arabic on Windows: set PYTHONUTF8=1.
  • No update popup: open the editor through npm run serve. From file:// it cannot check.

3Ask or report

  • GitHub issues for bugs and questions. Include the version (node update/cli.mjs --check) and the gate line you saw.
  • Never attach client documents, credentials or real personal data. Use the sample service to show the problem.
  • Security problem: report it privately, as SECURITY.md explains, or through the contact on the portfolio. Please do not open a public issue for it.

الدعم

آخر تحديث 2026-10-28

ابدأ بالدليل. وإن بقيت المشكلة فافتح بلاغا على GitHub.

في هذه الصفحة

  1. اقرأ أولا
  2. حلول شائعة
  3. اسأل أو أبلغ

1اقرأ أولا

  • الدليلالمتطلبات، والبدء السريع، وحل المشكلات، والنسخ الاحتياطي، والتسليم
  • ما الذي تغيركل إصدار، مع ملاحظات الترحيل
  • خادم MCPكل أداة ووسائطها

2حلول شائعة

  • التصدير أو الطباعة لا يفعل شيئا: افتح المحرر عبر npm run serve، لا من الملف على القرص.
  • الخطوط صحيحة في المحرر وخاطئة في PDF: اطبع من نسخ TrueType (انظر fonts/README.md).
  • توقف Python عند طباعة العربية على Windows: اضبط PYTHONUTF8=1.
  • لا تظهر نافذة التحديث: افتح المحرر عبر npm run serve، فمن file:// لا يستطيع الفحص.

3اسأل أو أبلغ

  • بلاغات GitHub للأعطال والأسئلة. اذكر الإصدار (node update/cli.mjs --check) وسطر الفحص الذي ظهر لك.
  • لا ترفق وثائق العملاء ولا بيانات الدخول ولا بيانات شخصية حقيقية. استخدم الخدمة النموذجية لتوضيح المشكلة.
  • مشكلة أمنية: أبلغ عنها بشكل خاص كما يشرح SECURITY.ar.md، أو عبر وسيلة التواصل في الموقع الشخصي، ولا تفتح لها بلاغا عاما.
