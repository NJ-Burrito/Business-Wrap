How it works

Evidence, then the editor, then PDF and DOCX

  1. {{icon:process-model}}{{icon:walk}}

    Evidence

    A process model gives roles, workflow, rules and statuses. A walk through the live service gives the card, the form, attachments and messages. The merge keeps both.

  2. {{icon:editor}}{{icon:direction}}

    Editor

    One HTML file. The page you edit is the page that prints. Every change is recorded and can be undone.

  3. {{icon:pdf}}{{icon:docx}}

    PDF + DOCX

    Both editions, with the fonts embedded as real, selectable text. Plus the edits file and a design pack.

Install

Pick one way in

All three run on your computer.

{{icon:plugin}}Easiest

Claude Code plugin

The skill and the MCP server together.

/plugin marketplace add NJ-Burrito/Business-Wrap
/plugin install business-wrap@business-wrap
{{copy}}

Then say "build the requirements document for …" or "open it in the editor".

{{icon:mcp-server}}Any MCP client

MCP server

Get the code (clone, or the release zip with its .sha256), run npm ci, then:

claude mcp add business-wrap -- node <path>/Business-Wrap/mcp/cli.mjs
{{copy}}

Latest release zip. Needs Node 20+, Chrome or Edge for the PDF, uv for the DOCX.

{{icon:editor}}No agent

From source

Build the sample and open it in the editor.

git clone https://github.com/NJ-Burrito/Business-Wrap
cd Business-Wrap
npm ci
npm run sample
npm run serve
{{copy}}

Opens on http://127.0.0.1:4317/ with one-click PDF + DOCX.

Updates

New versions reach you, with your consent

  • {{icon:update}}
    In the editorOpened through npm run serve, it checks at launch, at most once a day. A popup shows what is new: Update now, Later, or Skip.
  • {{icon:export}}
    Your work is never touchedProgram files only. Documents, edits, fonts and logos stay. Any failure puts the previous version back.
  • {{icon:plugin}}
    Claude Code plugin/plugin marketplace update business-wrap, then /plugin update business-wrap.
  • {{icon:mcp-server}}
    Terminal or agentnode update/cli.mjs --check, then --apply --yes. Every version is a GitHub release.

FAQ

Short answers

Is it free?{{ui:chevron}}

Yes. MIT licence, no paid plan, no account.

Does my document leave my computer?{{ui:chevron}}

No. The editor, the PDF printer and the DOCX builder run locally.

The one automatic request is the update check: at most once a day, to the public GitHub release list. Webhooks send only to an address you set.

Do I need Claude?{{ui:chevron}}

No. The editor and the command line work on their own. The plugin and the MCP server are optional.

What goes in, what comes out?{{ui:chevron}}

In: a process model (BPMN, draw.io, YAML) or a crawl of a live service.

Out: PDF, DOCX, the edits JSON, a design pack, and the editor saved as HTML.

Will the crawler file a real request?{{ui:chevron}}

Not unless you ask twice: submit: true in the config and --yes-file-real-request. Otherwise it stops before Send, Submit, Confirm or Pay.

Which fonts can I use?{{ui:chevron}}

Thmanyah by default, any font on your computer, or a file you upload. The font's licence is your responsibility; font files are not included.

What does it run on?{{ui:chevron}}

Tested on Windows 11 with Node 24 and Chrome. It needs Node 20+, Chrome or Edge, and Python with uv for DOCX. macOS and Linux are untested.

أسئلة شائعة

إجابات قصيرة

هل هو مجاني؟{{ui:chevron}}

نعم. رخصة MIT، بلا خطة مدفوعة وبلا حساب.

هل تغادر وثيقتي جهازي؟{{ui:chevron}}

لا. المحرر وطابعة PDF ومنشئ DOCX تعمل كلها على جهازك.

الطلب التلقائي الوحيد هو فحص التحديث: مرة في اليوم على الأكثر، إلى قائمة الإصدارات العامة على GitHub. وخطافات الويب ترسل فقط إلى عنوان تحدده أنت.

هل أحتاج Claude؟{{ui:chevron}}

لا. المحرر وسطر الأوامر يعملان وحدهما. والإضافة وخادم MCP اختياريان.

ماذا يدخل وماذا يخرج؟{{ui:chevron}}

يدخل: نموذج إجراء (BPMN أو draw.io أو YAML) أو مسح لخدمة حية.

يخرج: PDF وDOCX وملف التعديلات JSON وحزمة التصميم والمحرر محفوظا بصيغة HTML.

هل يقدّم المسح طلبا حقيقيا؟{{ui:chevron}}

لا، إلا إذا طلبت ذلك مرتين: submit: true في الإعدادات و--yes-file-real-request. وإلا توقف قبل الإرسال أو التقديم أو التأكيد أو الدفع.

أي الخطوط أستخدم؟{{ui:chevron}}

خط ثمانية افتراضيا، أو أي خط على جهازك، أو ملف ترفعه. ترخيص الخط مسؤوليتك، وملفات الخطوط غير مضمّنة.

على أي نظام يعمل؟{{ui:chevron}}

جُرّب على Windows 11 مع Node 24 وChrome. ويحتاج Node 20 أو أحدث، وChrome أو Edge، وPython مع uv لملفات DOCX. ولم يُجرَّب على macOS ولينكس.
