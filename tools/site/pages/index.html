01

Evidence, then the editor, then PDF and DOCX

01

الأدلة، ثم المحرر، ثم PDF وDOCX

  1. 1.1
    {{icon:process-model}}{{icon:walk}}

    Evidence

    A process model gives roles, workflow, rules and statuses. A walk through the live service gives the card, the form, attachments and messages. The merge keeps both.

  2. 1.2
    {{icon:editor}}{{icon:direction}}

    Editor

    One HTML file. The page you edit is the page that prints. Every change is recorded and can be undone.

  3. 1.3
    {{icon:pdf}}{{icon:docx}}

    PDF + DOCX

    Both editions, with the fonts embedded as real, selectable text. Plus the edits file and a design pack.

  1. 1.1
    {{icon:process-model}}{{icon:walk}}

    الأدلة

    نموذج الإجراء يعطي الأدوار وسير العمل والقواعد والحالات. والجولة في الخدمة الحية تعطي البطاقة والنموذج والمرفقات والرسائل. والدمج يحتفظ بالاثنين.

  2. 1.2
    {{icon:editor}}{{icon:direction}}

    المحرر

    ملف HTML واحد. الصفحة التي تحررها هي الصفحة التي تطبع. كل تغيير مسجل ويمكن التراجع عنه.

  3. 1.3
    {{icon:pdf}}{{icon:docx}}

    PDF وDOCX

    النسختان معا، والخطوط مضمنة نصا حقيقيا قابلا للتحديد. ومعهما ملف التعديلات وحزمة التصميم.

cd Business-Wrap
npm ci
npm run sample
npm run serve
{{copy}}

Opens on http://127.0.0.1:4317/ with one-click PDF + DOCX. Chrome or Edge for the PDF, uv for the DOCX.

05

Is it safe?

05

هل هو آمن؟

  • {{ui:shield-check}}Local only

    The editor, the PDF printer and the DOCX builder run on your computer. Nothing is uploaded.

  • {{ui:shield-check}}Once a day

    The one automatic request is the update check, to the public GitHub release list, with no account. Switch it off in Settings or with node update/cli.mjs --off.

  • {{ui:shield-check}}Dry run

    The crawler stops before Send, Submit, Confirm or Pay. Filing a real request needs submit: true and --yes-file-real-request.

  • {{ui:shield-check}}Every commit

    A security gate keeps client content, credentials and local paths out of the repository.

  • {{ui:shield-check}}على جهازك فقط

    المحرر وطابعة PDF ومنشئ DOCX تعمل على جهازك. لا يرفع أي شيء.

  • {{ui:shield-check}}مرة في اليوم

    الطلب التلقائي الوحيد هو فحص التحديث، إلى قائمة الإصدارات العامة على GitHub، بلا حساب. أوقفه من الإعدادات أو بالأمر node update/cli.mjs --off.

  • {{ui:shield-check}}تشغيل تجريبي

    المسح يتوقف قبل الإرسال أو التقديم أو التأكيد أو الدفع. وتقديم طلب حقيقي يحتاج submit: true و--yes-file-real-request.

  • {{ui:shield-check}}كل إيداع

    فحص أمني يبقي محتوى العملاء وبيانات الدخول والمسارات المحلية خارج المستودع.

06

Short answers

06

إجابات قصيرة

Is it free?{{ui:chevron}}

Yes. MIT licence, no paid plan, no account.

Does my document leave my computer?{{ui:chevron}}

No. The editor, the PDF printer and the DOCX builder run locally.

The one automatic request is the update check: at most once a day, to the public GitHub release list. Webhooks send only to an address you set.

Do I need Claude?{{ui:chevron}}

No. The editor and the command line work on their own. The plugin and the MCP server are optional.

What goes in, what comes out?{{ui:chevron}}

In: a process model (BPMN, draw.io, YAML) or a crawl of a live service.

Out: PDF, DOCX, the edits JSON, a design pack, and the editor saved as HTML.

Will the crawler file a real request?{{ui:chevron}}

Not unless you ask twice: submit: true in the config and --yes-file-real-request. Otherwise it stops before Send, Submit, Confirm or Pay.

Which fonts can I use?{{ui:chevron}}

Thmanyah by default: your own copy wins, and a bundled fallback (under the Thmanyah licence, not MIT) makes the PDF right out of the box. Any font on your computer, or a file you upload, also works; its licence is your responsibility.

What does it run on?{{ui:chevron}}

Tested on Windows 11 with Node 24 and Chrome. It needs Node 20+, Chrome or Edge, and Python with uv for DOCX. macOS and Linux are untested.

هل هو مجاني؟{{ui:chevron}}

نعم. رخصة MIT، بلا خطة مدفوعة وبلا حساب.

هل تغادر وثيقتي جهازي؟{{ui:chevron}}

لا. المحرر وطابعة PDF ومنشئ DOCX تعمل كلها على جهازك.

الطلب التلقائي الوحيد هو فحص التحديث: مرة في اليوم على الأكثر، إلى قائمة الإصدارات العامة على GitHub. وخطافات الويب ترسل فقط إلى عنوان تحدده أنت.

هل أحتاج Claude؟{{ui:chevron}}

لا. المحرر وسطر الأوامر يعملان وحدهما. والإضافة وخادم MCP اختياريان.

ماذا يدخل وماذا يخرج؟{{ui:chevron}}

يدخل: نموذج إجراء (BPMN أو draw.io أو YAML) أو مسح لخدمة حية.

يخرج: PDF وDOCX وملف التعديلات JSON وحزمة التصميم والمحرر محفوظا بصيغة HTML.

هل يقدم المسح طلبا حقيقيا؟{{ui:chevron}}

لا، إلا إذا طلبت ذلك مرتين: submit: true في الإعدادات و--yes-file-real-request. وإلا توقف قبل الإرسال أو التقديم أو التأكيد أو الدفع.

أي الخطوط أستخدم؟{{ui:chevron}}

ثمانية افتراضيا: نسختك أنت لها الأولوية، ونسخة احتياطية مضمنة (تحت رخصة ثمانية لا MIT) تطبع PDF صحيحا من أول مرة. ويعمل أيضا أي خط على جهازك أو ملف ترفعه، وترخيصه مسؤوليتك.

على أي نظام يعمل؟{{ui:chevron}}

جرب على Windows 11 مع Node 24 وChrome. ويحتاج Node 20 أو أحدث، وChrome أو Edge، وPython مع uv لملفات DOCX. ولم يجرب على macOS ولينكس.
